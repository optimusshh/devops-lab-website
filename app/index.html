CONTINUOUS INTEGRATION & DEPLOYMENT

Our delivery pipeline.

A developer pushes code to GitHub. Jenkins detects the change and executes the pipeline.

01

Checkout

Retrieve the application source from GitHub.

02

Build

Prepare the website deployment artifact.

03

Test

Validate HTML, CSS, JavaScript and artifact files.

04

Backup

Preserve the previously deployed application.

05

Deploy

Transfer the website to the application server.

06

Verify and Rollback

Check HTTP responses and restore the previous release if verification fails.
